# Resume Writer 中文版

该技能用于把本项目包装成高质量简历项目经历。

## 核心模型

```text
写作原则 + 项目亮点 + 用户画像 = 定制化简历项目经历
```

## 工作流程

1. 加载简历写作原则和项目亮点。
2. 采集用户画像：
   - 目标岗位
   - 真实业务背景
   - 技术侧重
   - 特殊要求
3. 根据岗位筛选亮点：
   - RAG 工程：Hybrid Search、Ingestion、多模态、评估体系
   - 后端/架构：可插拔架构、工程化、可观测性、DocumentManager
   - Agent 工程：Agent/Skill、MCP、Hybrid Search、可插拔架构
4. 按“四段式结构”生成内容：
   - 背景
   - 目标
   - 过程
   - 结果
5. 输出可用于简历的项目描述，必要时提供中英文版本。

## 写作重点

背景段必须尽量来自用户真实业务场景，避免空泛模板。技术亮点要体现工程复杂度、架构设计和可量化结果。
