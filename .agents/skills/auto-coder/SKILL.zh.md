# Auto Coder 中文版

触发后完成一条完整链路：读取规格 -> 查找任务 -> 编码实现 -> 测试验证 -> 持久化进度。

可选参数：
- 指定任务 ID，例如 `auto code B2`
- 使用 `--no-commit` 跳过 Git 提交

## 流程

```text
同步规格 -> 查找任务 -> 实现 -> 测试（最多 3 轮修复）-> 持久化
```

执行 Python 或 pytest 前必须激活 `.venv`。

## 参考文件

参考资料位于 `.agents/skills/auto-coder/references/`：
- `01-overview.md`：项目概览与目标
- `02-features.md`：功能规格
- `03-tech-stack.md`：技术栈与依赖
- `04-testing.md`：测试约定
- `05-architecture.md`：架构与模块设计
- `06-schedule.md`：任务排期与状态
- `07-future.md`：后续规划

## 执行规则

1. 同步规格并读取排期。
2. 优先选择进行中的任务，其次选择第一个未开始任务。
3. 读取相关规格，提取输入输出、设计原则、文件范围和验收标准。
4. 按项目现有架构实现，优先遵循可插拔、配置驱动和工厂模式。
5. 运行相关测试，失败时诊断并最多修复 3 轮。
6. 更新进度文件，必要时创建提交。
