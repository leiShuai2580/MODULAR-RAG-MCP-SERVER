# QA Tester 中文版

该技能用于全自动执行项目 QA 测试。所有测试必须严格串行执行，不能并行。

## 铁律

1. 一次只选一个测试、运行一个命令、记录一行进度。
2. 只有本次会话真实终端输出能证明通过，才允许标记通过。
3. 禁止用“已在其他测试验证”之类交叉引用代替本测试证据。
4. 禁止推断式通过，必须以实际输出为准。
5. 以发现问题为目标，不做表演式确认。
6. 每个章节结束后运行 notes 校验脚本，修正不合格记录。

## 流程

```text
选择一个待测项 -> 准备状态 -> 运行一个命令 -> 对照预期验证 -> 修复（最多 3 轮）-> 记录进度 -> 下一个
```

## 测试类别

- Dashboard UI：使用 Streamlit AppTest 进行无头渲染测试
- CLI：运行命令并检查退出码和输出
- MCP Protocol：通过 JSON-RPC 子进程测试协议
- Provider Switch：切换配置后执行验证
- Data Lifecycle：执行多步骤数据生命周期检查

## 输出要求

测试记录必须包含真实命令输出中的具体值。没有输出证据时不能标记通过。
